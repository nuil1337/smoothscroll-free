# SmoothScroll

[🇬🇧 English version](README.md)

Лёгкая фоновая утилита для Windows, которая заменяет резкие прыжки колёсика
мыши на 3 строки плавной прокруткой с инерцией и анимацией — открытый аналог
известного приложения SmoothScroll.

![.NET 8](https://img.shields.io/badge/.NET-8.0-blueviolet) ![Windows 10/11](https://img.shields.io/badge/Windows-10%20%2F%2011-0078d4) ![single exe](https://img.shields.io/badge/build-single%20exe-success)

## Возможности

- **Прокрутка с инерцией** — три характера движения: плавная инерция
  (по умолчанию), равномерная и мягкое торможение.
- **Настраиваемый шаг** — во сколько раз больше/меньше прокручивать за щелчок
  (0.25×–4×).
- **Длительность анимации** — 100–1200 мс.
- **Ускорение** — при серии быстрых щелчков прокрутка разгоняется (до 3×).
- **Горизонтальное колесо** — плавная прокрутка при наклоне колеса.
- **Исключения** — чёрный список процессов (например, игр), которым остаётся
  обычная прокрутка.
- **Автозапуск с Windows** — одной галочкой.
- Высокоточные тачпады и события колеса, инжектируемые другими программами,
  не трогаются — они уже плавные.

Все изменения применяются мгновенно (без перезапуска) и сохраняются в
`%APPDATA%\SmoothScroll\settings.json`.

## Запуск

Готовый однофайловый exe (устанавливать .NET не нужно):

```
publish\SmoothScroll.exe
```

Приложение садится в область уведомлений (рядом с часами):

- **двойной клик** по значку — окно настроек;
- **правый клик** — меню: Включено / Настройки / Запускать с Windows / Выход.

## Сборка из исходников

Требуется .NET 8 SDK.

```bat
dotnet build -c Release

rem однофайловый автономный exe:
dotnet publish -c Release -r win-x64 --self-contained ^
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true ^
  -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -o publish
```

## Как это устроено

1. Низкоуровневый хук мыши (`WH_MOUSE_LL`) работает в отдельном потоке
   с повышенным приоритетом и перехватывает `WM_MOUSEWHEEL` / `WM_MOUSEHWHEEL`.
2. Классические щелчки колеса (|Δ| ≥ 100) поглощаются. Каждый импульс
   отправляется в lock-free очередь — **поток хука никогда не блокируется**.
   Это принципиально: заблокированный низкоуровневый хук упирается в системный
   таймаут (300 мс), и тогда лагает вся мышь.
3. Отдельный поток анимации (тоже с повышенным приоритетом) разбирает очередь
   и, в такт высокоточному waitable-таймеру (~125 Гц, Windows 10 1803+,
   с откатом на `timeBeginPeriod(1)`), инжектирует дробные шаги прокрутки через
   `SendInput` по выбранной кривой. Дробные остатки копятся, поэтому итоговое
   смещение в точности равно целевому.
4. Собственные события помечены меткой в `dwExtraInfo` — хук их пропускает,
   рекурсии не возникает.
5. Медленная работа (определение процесса окна под курсором для чёрного
   списка) никогда не выполняется в потоке хука — она вынесена в поток
   анимации, а неопознанные окна просто прокручиваются нативно.

### Советы по настройке

- В списках с построчной прокруткой (проводник, диспетчер задач) анимация
  заметнее всего при **большей длительности** (500–700 мс) и профиле
  **«мягкое торможение»**.
- В приложениях с попиксельной прокруткой (браузеры, редакторы) хорошо
  выглядит экспоненциальная инерция по умолчанию.

## Замечания

- Если прокрутка не работает в окне, запущенном **от имени администратора**,
  это ограничение Windows (UIPI): запустите SmoothScroll тоже с повышенными
  правами.
- Игры, читающие «сырой» ввод, обычно и так проходят мимо хуков; при
  необходимости добавьте их в исключения.
